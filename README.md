One-line office joke for make.fun's "Make the AI Judge Laugh: Office Jokes" bounty. A single exit-interview joke, 105 characters: the setup asks what would have made the worker stay, and the punchline answers that the fix was this very interview, three years too late. The joke lives in `main.py`, which writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` using only the standard library.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py && cat ./output/entry.txt
```
